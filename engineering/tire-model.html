Pacejka Tire Model Development

A MATLAB tool that turns raw tire test data from Calspan into tire behavior curves, built for Crimson Racing's vehicle dynamics work.

Data source
Calspan FSAE Tire Testing Consortium (TTC)
Model
Pacejka Magic Formula
Languages Used
MATLAB, Python
Outputs
Pacejka coefficients, tire-road interaction forces

The tool ingests raw Calspan TTC data and automatically extracts the file structure across the variables that matter for characterizing a tire: slip angle (SA), inclination angle (IA / camber), and pressure. From there it smooths and fits the raw force and moment data into usable curves.

  • Parses and organizes hundreds of raw test files by sweep variable (SA, IA, pressure) instead of handling them one at a time.
  • Smooths and fits raw lateral force and moment data using the Pacejka Magic Formula.
  • Outputs lateral force vs. slip angle (Fy–SA) and aligning moment vs. slip angle (Mz–SA) characterization curves, the core inputs for suspension and setup decisions.
  • Not yet wired into a lap sim. Right now it's a standalone characterization tool, with that integration as a future step.

Currently being rebuilt: the MATLAB codebase is being translated to Python and paired with a GUI, so future vehicle dynamics team members without a MATLAB license or scripting background can run a characterization without touching code.
